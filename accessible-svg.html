Accessible SVG Demo

Why Accessibility Matters

Making SVGs accessible ensures that all users, including those using screen readers or other assistive technologies, can understand and interact with your graphics. This demo shows best practices for creating accessible SVG graphics.

1. Decorative vs. Informative SVGs

Decorative SVG (Hidden from Screen Readers)

Use Case: When the SVG is purely decorative and doesn't convey meaningful information.

<svg aria-hidden="true" focusable="false">
  <circle cx="50" cy="50" r="40" fill="#E91E63"/>
</svg>

✓ Use aria-hidden="true" and focusable="false" for decorative graphics.

Informative SVG (Announced by Screen Readers)

Use Case: When the SVG conveys important information.

<svg role="img" aria-labelledby="circle-title">
  <title id="circle-title">A green circle representing a successful action</title>
  <circle cx="50" cy="50" r="40" fill="#4CAF50"/>
</svg>

✓ Use role="img", <title>, and aria-labelledby for meaningful graphics.

2. Using Title and Description Elements

Best Practice: Combine <title> and <desc> for detailed information.

<svg role="img" aria-labelledby="chart-title chart-desc">
  <title id="chart-title">Sales Growth Chart</title>
  <desc id="chart-desc">A bar chart showing 30% increase in sales from Q1 to Q2 2024</desc>
  <!-- chart elements -->
</svg>

✓ <title> provides a short label, <desc> gives detailed description.

3. Interactive SVG with Keyboard Support

Accessible Button with SVG Icon:

<button type="button">
  <svg aria-hidden="true" focusable="false">
    <path fill="currentColor" d="M19 13h-6v6h-2v-6H5v-2h6V5h2v6h6v2z"/>
  </svg>
  Add Item
</button>

✓ Icon is decorative; button text provides context. Focus is on the button, not the SVG.

Icon-Only Button (Requires aria-label):

<button type="button" aria-label="Close dialog">
  <svg aria-hidden="true" focusable="false">
    <path fill="currentColor" d="M19 6.41..."/>
  </svg>
</button>

⚠ Icon-only buttons must have aria-label to describe their purpose.

4. Color Contrast and Visual Accessibility

Poor Contrast:

✗ Insufficient color contrast (1.2:1 ratio)

Good Contrast:

✓ Sufficient color contrast (8.4:1 ratio)

Use tools like WebAIM's Contrast Checker to ensure text meets WCAG AA standards (4.5:1 for normal text).

5. Providing Text Alternatives

Using aria-label

Quick and simple alternative for simple graphics:

<svg role="img" aria-label="Green checkmark indicating success">
  <!-- graphic elements -->
</svg>

Using Long Description for Complex Graphics

For complex infographics or data visualizations:

<svg role="img" aria-labelledby="title" aria-describedby="desc">
  <title id="title">User Growth Trend</title>
  <desc id="desc">Detailed description of data...</desc>
  <!-- graphic elements -->
</svg>

6. Accessibility Checklist

  • ✓ Use role="img" for informative SVGs
  • ✓ Add aria-hidden="true" and focusable="false" for decorative SVGs
  • ✓ Provide <title> element with unique id
  • ✓ Add <desc> for complex graphics needing detailed description
  • ✓ Use aria-labelledby to reference title (and desc if present)
  • ✓ Ensure sufficient color contrast (minimum 4.5:1 for text)
  • ✓ Don't rely solely on color to convey information
  • ✓ Make interactive SVGs keyboard accessible
  • ✓ Test with screen readers (NVDA, JAWS, VoiceOver)
  • ✓ Keep SVG markup semantic and structured

7. Common Patterns Summary

Decorative SVG Pattern:

<svg aria-hidden="true" focusable="false">
  <!-- decorative graphics -->
</svg>

Simple Informative SVG Pattern:

<svg role="img" aria-label="Description of image">
  <!-- graphics -->
</svg>

Complex Informative SVG Pattern:

<svg role="img" aria-labelledby="title-id desc-id">
  <title id="title-id">Short title</title>
  <desc id="desc-id">Detailed description</desc>
  <!-- graphics -->
</svg>

Icon in Button Pattern:

<button aria-label="Action description">
  <svg aria-hidden="true" focusable="false">
    <!-- icon graphics -->
  </svg>
</button>
