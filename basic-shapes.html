SVG Basic Shapes Demo

1. Circle

A circle is defined by cx (center x), cy (center y), and r (radius).

2. Rectangle

A rectangle is defined by x, y, width, and height. Rounded corners with rx and ry.

3. Ellipse

An ellipse uses cx, cy, rx (horizontal radius), and ry (vertical radius).

4. Line

A line is drawn between two points: (x1, y1) and (x2, y2).

5. Polyline

A polyline creates connected lines through multiple points defined in the points attribute.

6. Polygon

A polygon is a closed shape with multiple points. The last point automatically connects to the first.

7. Path

The path element is the most powerful. It uses commands: M (move), L (line), C (curve), Z (close path).

8. Combined Shapes with Grouping

Using <g> to group elements with shared attributes.

9. Transparency and Gradients

Using opacity and fill-opacity for transparency effects.
